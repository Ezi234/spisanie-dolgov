# Банкротство физических лиц — сайт-лендинг

Одностраничный сайт на чистом HTML, CSS и JS: без фреймворков и сборки, все файлы лежат в папке.

Адрес: https://ezi234.github.io/spisanie-dolgov/  
Репозиторий: https://github.com/Ezi234/spisanie-dolgov

Чтобы сменить, например, телефон, замените его во всём `index.html` через «Найти и заменить».

Номера показаны вместе в шапке, на первом экране, в карточке «Позвонить» и в подвале.
Кнопки «Позвонить» без номера (у них атрибут `data-call`) открывают окно с выбором из двух номеров.

### МАКС

У МАКС нет ссылки, которая открывает чат по номеру телефона (как `wa.me` у WhatsApp).
Поэтому значок МАКС открывает окно с номером, кнопкой «Скопировать номер» и кнопкой «Открыть МАКС».

Чтобы значок сразу открывал ваш профиль:
1. В приложении МАКС откройте Профиль, нажмите значок QR-кода и выберите «Поделиться ссылкой».
2. Получится ссылка вида `https://max.ru/u/...`.
3. Вставьте её в `js/main.js`, в строку `maxProfile: ''`, между кавычками.

## Заявка без сервера

На GitHub Pages нет сервера, поэтому форма ничего никуда не отправляет сама.
Человек вводит имя, сумму долга и пару слов о ситуации, а страница составляет готовое сообщение:
- на телефоне кнопка «Отправить SMS» открывает SMS на номер с этим текстом;
- на компьютере кнопка «Скопировать заявку» копирует текст;
- кнопки МАКС и ВК копируют текст и открывают чат, остаётся только вставить его.

Ответы из теста «Подходит ли банкротство» кнопкой «Отправить ответы юристу» переносятся в заявку.

## Чат с помощником

Чат открывают плавающая кнопка справа внизу, кнопка «Чат» в нижней панели на телефоне
и кнопка «Спросить помощника» в разделе вопросов. Сервер не нужен: бот работает прямо в браузере.

Что умеет:
- отвечает по существу на вопросы о стоимости, сроках, МФЦ, жилье, ипотеке, машине, зарплате,
  коллекторах, документах, последствиях, выезде за границу, родственниках;
- понимает сообщение целиком: достаёт сумму долга («450к», «полтора ляма», «триста тысяч»),
  виды долгов и имущество и по сумме подсказывает путь — МФЦ или суд;
- прощает опечатки («сколко стоит», «банкроство»), не повторяет один и тот же ответ слово в слово;
- вежливо отвечает на грубость, вопросы не по теме и «ты бот?»;
- юриста предлагает отдельной кнопкой, а не в каждом ответе; если вопрос непонятен,
  сначала просит уточнить и только со второго раза предлагает передать вопрос юристу;
- с 18:00 до 9:00 пишет, что юрист ответит завтра (или сегодня, если ночь) в 9:00;
- передаёт вопрос юристу: спрашивает имя и собирает сообщение из всей переписки —
  сумма, долги, имущество, вопросы. Его отправляют в МАКС, ВКонтакте или SMS (текст копируется сам).

Где менять:
- часы работы, выходные дни, телефоны, цена — в начале `js/chat-brain.js`, блок `CFG`.
  Сейчас юристы считаются на связи каждый день с 9:00 до 18:00 по Москве.
  Если по выходным не работаете, уберите `0` и `6` из `workDays` —
  тогда в пятницу вечером бот напишет «ответим в понедельник в 9:00»;
- ответы — там же, в списке `KB`: у каждой темы есть слова, по которым она узнаётся (`kw`), и текст ответа (`a`).

Переписка сохраняется, пока открыта вкладка: при обновлении страницы чат не обнуляется.

## QR-код для визиток

Папка `qr/`. Код ведёт на `https://ezi234.github.io/spisanie-dolgov/` — ровно этот адрес,
без перенаправлений. Уровень коррекции Q: код читается, даже если повреждена четверть его площади.

| Файл | Для чего |
|---|---|
| `qr-site.pdf`, `qr-site.eps` | Вектор для типографии, чёрный 100% K, 30×30 мм (масштабируется без потерь) |
| `qr-site.svg` | Вектор для Figma, Illustrator, Inkscape, CorelDRAW |
| `qr-site.png` | Растр 2050×2050 px — для Word, Canva и онлайн-конструкторов визиток |
| `qr-site-green.svg`, `qr-site-green.png` | Тот же код в тёмно-зелёном цвете сайта |
| `qr-test-print.pdf` | Лист A4 для пробной печати: коды 15–40 мм и требования для дизайнера |

На визитке: от 20 мм, лучше 25 мм, белая рамка вокруг кода входит в размер.
Тёмный код на белом фоне, без логотипа в середине, без растягивания.

**Адрес сайта менять нельзя**: напечатанные визитки ведут именно на него.
Если переименовать репозиторий или переехать на другой хостинг, все старые визитки перестанут работать.

## Что внутри

- `index.html` — разметка и все тексты.
- `css/style.css` — оформление и анимации.
- `js/main.js` — живая карточка долгов с конфетти, счётчики, вкладки, мифы, тест, заявка,
  вопросы-ответы, кнопка и нижняя панель связи, окно МАКС.
- `fonts/` — шрифт Geologica (лицензия SIL OFL), подключён локально.
- `img/og-cover.jpg` — картинка-превью для ссылок в ВК, МАКС и Telegram.
