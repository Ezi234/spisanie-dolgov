Чтобы сменить, например, телефон, замените его во всём `index.html` через «Найти и заменить».

### МАКС

У МАКС нет ссылки, которая открывает чат по номеру телефона (как `wa.me` у WhatsApp).
Поэтому значок МАКС открывает окно с номером, кнопкой «Скопировать номер» и кнопкой «Открыть МАКС».

Чтобы значок сразу открывал ваш профиль:
1. В приложении МАКС откройте Профиль, нажмите значок QR-кода и выберите «Поделиться ссылкой».
2. Получится ссылка вида `https://max.ru/u/...`.
3. Вставьте её в `js/main.js`, в строку `maxProfile: ''`, между кавычками.

## Заявка без сервера

На GitHub Pages нет сервера, поэтому форма ничего никуда не отправляет сама.
Человек вводит имя, сумму долга и пару слов о ситуации, а страница составляет готовое сообщение:
- на телефоне кнопка «Отправить SMS» открывает SMS на номер с этим текстом;
- на компьютере кнопка «Скопировать заявку» копирует текст;
- кнопки МАКС и ВК копируют текст и открывают чат, остаётся только вставить его.

Ответы из теста «Подходит ли банкротство» кнопкой «Отправить ответы юристу» переносятся в заявку.

## Что внутри

- `index.html` — разметка и все тексты.
- `css/style.css` — оформление и анимации.
- `js/main.js` — живая карточка долгов с конфетти, счётчики, вкладки, мифы, тест, заявка,
  вопросы-ответы, кнопка и нижняя панель связи, окно МАКС.
- `fonts/` — шрифт Geologica (лицензия SIL OFL), подключён локально.
- `img/og-cover.jpg` — картинка-превью для ссылок в ВК, МАКС и Telegram.
